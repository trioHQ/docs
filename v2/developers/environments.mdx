Trio offers two environments, sandbox and production, each with its own base URL. Every V2 path starts with `/v2`, so a request to list your entities in the sandbox is `https://api.sandbox.trio.com.br/v2/entities`.

| Environment | Base URL | Use it for |
| --- | --- | --- |
| `sandbox` | [`https://api.sandbox.trio.com.br`](https://api.sandbox.trio.com.br) | Development, testing and experimentation. It is isolated from production, so nothing you do there affects real data. |
| `production` | [`https://api.trio.com.br`](https://api.trio.com.br) | Your deployed application serving end users. It holds real data: use it with care to prevent unintended actions. |

To create a sandbox account, follow the [Sandbox account](/v2/guides/sandbox_account) guide.

## Switching between environments

Keep the base URL in environment-specific configuration files or environment variables, so each deployment of your application talks to the right environment. When you move from testing to production, update that configuration to the production base URL.
