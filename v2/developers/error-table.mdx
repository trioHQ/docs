The V2 API groups outcomes by HTTP status code: `2xx` means the request worked as expected, `4xx` means it failed because of invalid information or a validation error, and `5xx` means something went wrong on Trio's side. Every error also returns a JSON body that tells you what went wrong, so you can handle it during the integration.

## Error body

- `error.error_code`: stable `UPPER_SNAKE` identifier of the error, for programs and logs. Branch on this, not on the message.
- `error.error_message`: human-readable explanation of the error.
- `error.errors`: only on `INVALID_PARAMETER` for a request outside the operation's schema, one entry per offending field, with a JSON pointer in `field` and what is wrong with it in `message`.

```json
{
  "error": {
    "error_code": "INVALID_PARAMETER",
    "error_message": "Invalid parameters: /amount: Invalid integer. Got: string",
    "errors": [
      {
        "field": "/amount",
        "message": "Invalid integer. Got: string"
      }
    ]
  }
}
```

## HTTP status codes

| Code | Type | Description |
| --- | --- | --- |
| 200 | Success | Everything worked as expected. |
| 201 | Success | Resource created successfully. |
| 204 | Success | Everything worked as expected with empty body. Updates and cancellations answer this way. |
| 400 | Bad request | Malformed request: a body that is not valid JSON, or a missing or outdated `Trio-Version` header. |
| 401 | Unauthorized | Missing or invalid API key credentials. |
| 403 | Forbidden | The API key may not do this, for instance a `Trio-Target-Org-Id` it has no access to, or a write through a read-only access. |
| 404 | Not Found | No resource with this ID. |
| 422 | Unprocessable | Invalid input: a field that fails validation, a missing required field, or a business rule the request breaks. |
| 429 | Too Many Requests | Too many requests, see [Rate limits](/v2/developers/rate-limit). |
| 500 | Server Error | Something went wrong in Trio's infrastructure. |
| 503 | Service Unavailable | A service needed to answer is unavailable. |

## Error codes

| Code | Status | Description |
| --- | --- | --- |
| MALFORMED_REQUEST | 400 | The body is not valid JSON. |
| INVALID_TRIO_VERSION | 400 | The `Trio-Version` header is missing or is not the current version. |
| INVALID_CREDENTIALS | 401 | Missing or invalid API key credentials. |
| FORBIDDEN | 403 | The API key may not perform this request on this organization. |
| NOT_FOUND_RESOURCE | 404 | No resource with this ID. |
| INVALID_PARAMETER | 422 | A field is invalid. When the request is outside the operation's schema, `errors` lists every offending field. |
| REQUIRED_PARAMETER | 422 | A required field is missing. |
| TRIO_SERVICE_UNAVAILABLE | 503 | A service needed to answer is unavailable. |
