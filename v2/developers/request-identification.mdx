---
title: "Request identification"
description: "Request identifiers and how to use them with support."
---

Every API request is assigned a unique request identifier. Quote it when you contact support: it lets the team locate and investigate that exact request.

## The X-Request-Id header

The identifier is returned in the `X-Request-Id` response header. It also appears in the URL of each request log in the [Trio App](https://app.sandbox.trio.com.br/developers/logs).

```text

```

## Contacting support

Including the request identifier ensures the fastest possible resolution. When you contact support, include:

- the request identifier, from the `X-Request-Id` header or the request logs in the Trio App;
- the `error_code` returned when the request failed (see [Error handling](/v2/developers/error-table));
- a description of the issue;
- any relevant code snippets or additional details.

The [Support](/v2/getting_started/support) page lists the channels and their availability.
