---
title: "Webhooks"
description: "Practical webhook handling for V2: creating a webhook, the notification structure and the event categories."
---

Webhooks let Trio notify your application when something happens, such as a payment settling or an onboarding being approved, so you do not have to poll the API. On the V2 API a webhook is registered with `POST /v2/webhooks`, chooses which event categories it receives and which payload version (`api_version`) Trio sends to it.
