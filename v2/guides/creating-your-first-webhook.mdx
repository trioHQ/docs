title: "First webhook"
description: "Register a webhook in the Trio App and start receiving event notifications."
---

Webhooks let Trio notify your application whenever an event occurs, so you do not need to poll the API for updates. This page registers your first webhook in the Trio App. You need an HTTPS endpoint that is publicly reachable and accepts HTTP `POST` requests.

<Steps>
  <Step title="Open Settings">
    In the lower-left menu, click the **Settings** icon.

    <Frame>
      ![Settings icon in the lower-left menu](/images/image-1.png)
    </Frame>
  </Step>
  <Step title="Go to Webhooks">
    In the dropdown menu, select **Webhooks**.

    <Frame>
      ![Webhooks option in the Settings menu](/images/image-2.png)
    </Frame>
  </Step>
  <Step title="Create a webhook">
    Click **Create Webhook**.

    <Frame>
      ![Create Webhook button](/images/image-3.png)
    </Frame>
  </Step>
  <Step title="Fill in the Notification URL">
    This is the HTTPS endpoint where Trio delivers webhook notifications. Make sure it is publicly accessible and accepts HTTP `POST` requests.

    <Frame>
      ![Notification URL field](/images/image-4.png)
    </Frame>
  </Step>
  <Step title="Select an Entity (optional)">
    Leave the field empty to receive events from **all entities** in your account, or select an entity to receive only the events related to it.

    <Frame>
      ![Entity selector](/images/image-5.png)
    </Frame>
  </Step>
  <Step title="Select a Bank Account (optional)">
    {/* TODO(v2): verify — the V2 webhook API (POST /v2/webhooks) has no bank_account_id filter; confirm whether the V2 app still offers this step or drop it. */}

    After selecting an entity, you can narrow the webhook further to one of its bank accounts. Only events generated by that bank account are delivered.

    <Frame>
      ![Bank account selector](/images/image-6.png)
    </Frame>
  </Step>
  <Step title="Select the events">
    Choose the event types your application should receive.

    <Frame>
      ![Event selection](/images/image-7.png)
    </Frame>

    {/* TODO(v2): verify — event names shown here are V1 app labels; confirm the labels the V2 app uses for Pix cash-in and cash-out documents. */}

    For most Pix integrations, the recommended events are:

    - **Payment Document** (Pix cash-out)
    - **Collecting Document** (Pix cash-in)

    You can also subscribe to any other events relevant to your integration.

    {/* TODO(v2): verify — the API lets a webhook choose api_version (v100 or v200) for its event payloads; confirm whether and where the V2 app exposes this setting. */}

    <Note>
      A V2 webhook also carries an `api_version` (`v100` or `v200`) that selects the version of the event payloads it receives; it defaults to `v100`. See the [create webhook API reference](/v2/api-reference/banking-api/developers/webhooks/create-webhook).
    </Note>
  </Step>
  <Step title="Enter a Secret">
    Choose any secret value that only your application knows. Trio uses it to generate a unique signing key for the webhook.

    <Frame>
      ![Secret field](/images/image-9.png)
    </Frame>

    {/* TODO(v2): verify — the x-webhook-signature header and HMAC-SHA256 signing are not described in the V2 spec; confirm they are unchanged for V2 webhooks. */}

    Every delivery includes the `x-webhook-signature` HTTP header with the HMAC-SHA256 signature of the request body. To verify a delivery, compute the HMAC-SHA256 of the received payload with the signing key shown on the webhook details page and compare it with the header. When they match, the request came from Trio and the payload was not modified in transit.
  </Step>
  <Step title="Save the webhook">
    Click **Save Webhook**.

    <Frame>
      ![Save Webhook button](/images/image-10.png)
    </Frame>
  </Step>
  <Step title="Save the signing key">
    Open the webhook details and store the signing key in a secure location. Your application needs it to verify the signature of every delivery.

    <Frame>
      ![Webhook details with the signing key](/images/image-11.png)
    </Frame>
  </Step>
</Steps>

Your webhook is active and ready to receive notifications.
