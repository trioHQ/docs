---
title: Boleto types
description: Choose the invoice_type and wallet_type values that classify a boleto when you create it.
---

When you create a boleto, two required fields classify it: `invoice_type` says which document or obligation originated the charge, and `wallet_type` says how the bank registers and manages the boleto. Both go in the body of [`POST /v2/in/boletos`](/v2/api-reference/banking-api/receivables/boletos/post); the [Create a boleto](/v2/guides/boleto/create-boleto) guide covers the rest of the request.

```json
"invoice_type": "invoice",
"wallet_type": "book_entry_electronic_bloquete"
```

## Invoice type

`invoice_type` represents the type of document that originated the charge: the reason the boleto was issued, such as an invoice, a tax invoice, a school fee or a duplicate. The right-hand column gives the Brazilian document name each value stands for. If no value matches your charge, use `others`.

## Wallet type

`wallet_type` is the collection wallet (*carteira de cobrança*): the operational method the bank uses to register, issue and manage the boleto. It does not change the information shown to the payer; it only tells the bank how to process the boleto.

### Default value

By default, use:

| Value | Collection wallet (Portuguese name) |
| --- | --- |
| `book_entry_electronic_bloquete` | Carteira Escritural Eletrônica (Bloquete) |

### All values

| Value | Collection wallet (Portuguese name) |
| --- | --- |
| `direct_electronic_partial_emission_booklet` | Cobrança Direta Eletrônica com emissão parcial de boleto |
| `book_entry_electronic_booklet` | Carteira Escritural Eletrônica (Boleto) |
| `direct_electronic_with_emission_booklet` | Cobrança Direta Eletrônica com emissão do boleto |
| `direct_electronic_no_emission_block_client` | Cobrança Direta Eletrônica sem emissão (cliente emite) |
| `direct_electronic_no_emission_block_us` | Cobrança Direta Eletrônica sem emissão (modalidade do banco) |
| `book_entry_electronic_bloquete` | Carteira Escritural Eletrônica (Bloquete) |
| `direct_electronic_no_emission_block_client2` | Cobrança Direta Eletrônica sem emissão (variante) |
| `direct_electronic_partial_emission_bloquete` | Cobrança Direta Eletrônica com emissão parcial (Bloquete) |
| `direct_electronic_with_emission_bloquete` | Cobrança Direta Eletrônica com emissão (Bloquete) |
| `direct_electronic_no_emission_us_emission` | Cobrança Direta Eletrônica sem emissão (variante) |
