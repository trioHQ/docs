---
title: "First API credential"
description: "Create a Client ID and Secret Key in the Trio App to authenticate your V2 API requests."
---

Every V2 request authenticates with a Client ID and a Secret Key. This page walks you through creating that pair in the sandbox [Trio App](https://app.sandbox.trio.com.br).

<Steps>
  <Step title="Open Settings">
    In the lower-left menu, click the **Settings** icon.

    <Frame>
      <img alt="Settings icon in the lower-left menu" src="/images/image-(21).png" />
    </Frame>
  </Step>
  <Step title="Go to API Keys">
    In the dropdown menu, select **API Keys**.

    <Frame>
      <img alt="API Keys option in the Settings menu" src="/images/image-(22).png" />
    </Frame>
  </Step>
  <Step title="Create a key">
    Click **Create Key**.

    <Frame>
      <img alt="Create Key button" src="/images/image-(23).png" />
    </Frame>
  </Step>
  <Step title="Name the credential">
    Enter a name or identifier for the credential.

    <Frame>
      <img alt="Credential name field" src="/images/image-(24).png" />
    </Frame>
  </Step>
  <Step title="Choose the permissions">
    Define whether the credential has **Read and Write** or **Read-Only** permissions.
  </Step>
  <Step title="Configure the allowed IP addresses">
    Register the IP address of the server that makes API requests and processes transactions. If you have questions about this configuration, contact [Trio Support](/v2/getting_started/support).

    <Frame>
      <img alt="Example of an allowed IP addresses configuration" src="/images/image-(25).png" />
    </Frame>
  </Step>
  <Step title="Save the key">
    Click **Save Key**, then enter your password and OTP code.

    <Frame>
      <img alt="Password and OTP confirmation" src="/images/image-(26).png" />
    </Frame>
  </Step>
  <Step title="Store the Secret Key">
    Store the Secret Key in a secure location, then click **Confirm** and **Go to Key Details**.

    <Frame>
      <img alt="Secret Key shown after the key is created" src="/images/image-(27).png" />
    </Frame>
  </Step>
  <Step title="Save the Client ID">
    Save the Client ID displayed on the key details screen.

    <Frame>
      <img alt="Client ID on the key details screen" src="/images/image-(28).png" />
    </Frame>
  </Step>
</Steps>

Your API credential is ready. Use the Client ID as the username and the Secret Key as the password, as described in [Authentication](/v2/developers/authentication).
